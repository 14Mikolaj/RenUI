# Security Policy

## Supported versions

RenUI is pre-1.0 software. Security fixes are applied to the latest published
release and the `main` branch; older 0.x releases may not receive patches.

| Version | Supported |
| --- | --- |
| 0.1.3 | Yes |
| Earlier releases | No |

## Report a vulnerability privately

Please do not disclose a suspected vulnerability in a public issue, discussion,
or pull request. Use
[GitHub's private vulnerability reporting](https://github.com/14Mikolaj/RenUI/security/advisories/new)
and include:

- the affected version or commit;
- the environment and build configuration;
- reproduction steps or a minimal proof of concept;
- the expected impact and any known mitigations; and
- whether the report may be credited publicly.

The maintainer will acknowledge the report, investigate it, and coordinate a
fix and disclosure when warranted. Please allow time for a patch to be prepared
before publishing technical details.

For ordinary bugs without a security impact, use the
[public issue forms](https://github.com/14Mikolaj/RenUI/issues/new/choose).
